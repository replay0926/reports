기본분석 소견

1. 물건 특성

  • 공부상 제2종근린생활시설이나 현황 주거용으로 사용 중인 지하층(지층) 물건
  • 빌라헤르메스 집합건물의 지층 103호
  • 용도 불일치(근린시설 vs 주거용)가 있어 대출 및 전입신고 관련 확인 필요

2. 가격 매력도

  • 감정가 1.2억 대비 51.2% 수준인 6,144만원에 4차 매각 예정
  • 3회 연속 유찰로 상당한 가격 하락이 이루어짐
  • 강제경매(지급명령 기반)이며 청구금액 7,000만원

3. 권리관계 주요 확인사항

  • 임차권자 김OO: 배당요구신청서(주택임대차) 제출 이력 있음 → 임차보증금 규모, 대항력 여부 확인 필수
  • 가압류권자: 경OOOOOOOO → 배당요구 신청 완료
  • 교부권자: 국(OOOOO)은 교부청구 해제함, 광OO(OOOO)은 교부청구 유지 중
  • 항고 내역 없음 (절차 안정적)

4. 주의사항

  • 지하층 물건 특성상 채광, 습기, 환기 상태 현장 확인 필수
  • 공부상 용도(근린시설)와 현황(주거용) 불일치 → 불법 용도변경 여부 확인
  • 주거용 사용 시 전입신고 가능 여부, 주택담보대출 가능 여부 확인 필요
  • 관리비 체납 여부 확인 필요 (집합건물)

5. 다음 단계

  • /auction-research: 시세조사(인근 매매/전세 시세), 용도지역, 재개발 여부 확인
