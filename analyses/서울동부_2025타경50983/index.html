재검토 조건

본건은 NOGO 판단이나, 아래 조건을 모두 충족 시 재검토 가능:
1. 매각물건명세서 열람 -> 인수되는 임차보증금 없음 확인
2. 등기부등본 열람 -> 말소기준권리 및 근저당 설정액 확인
3. 광진구청 확인 -> 용도변경(제2종근린->주택) 가능 확인
4. 국세 세목/금액 확인 -> 당해세 없거나 소액 확인
5. 현장 방문 -> 건물 상태 및 점유 현황 확인
6. 채무자 항고/정지 움직임 없음 재확인
단, R002(시장 동결) 적용으로 리스크 2개 이상 잔존 시에도 Conditional Go 불가. 모든 리스크가 해소되어야 GO 전환 가능.

권리관계 주요 포인트

1. 용도 불일치 (핵심 리스크)

  • 집합건축물대장상 **"제2종근린생활시설"**이나 현황은 주택으로 이용중

  • 주거용으로 사용 시 불법 용도변경에 해당할 수 있음
  • 향후 용도변경 비용 및 가능 여부 확인 필요

2. 임차인 존재

  • 임차인 김OO이 상가임대차 기반 권리신고 및 배당요구 (2025.10.14)
  • 배당요구종기 연기 이력 존재 (2025.10.16)
  • 임차인 답변서 제출 (2025.10.31)
  • 임차인의 대항력 유무, 보증금 규모 확인 필요 (등기부등본/현황조사서 확인 필수)

  • 공동소유: 채무자겸소유자 고OO + 소유자 김OO

3-2. 근린생활시설(상가) 시세 분석

본건은 건축물대장상 제2종근린생활시설이므로, 상가 시세 기준도 적용해야 합니다.

기준 시세 범위 비고
서울 상가 경매 낙찰가율 (2025 상반기) 56~60% 8년 만에 최저 수준
서울 소형 상가 평당가 1,500~3,000만/평 위치/층/임대 현황에 따라 큰 편차
중곡동 1층 소형 상가 2,000~3,500만/평 (추정) 역세권 근접도에 따라 차이

핵심: 상가 경매 시장은 2025~2026년 급격히 냉각. 낙찰가율 56% 수준이며 30%대 낙찰 사례도 다수. 본건이 상가 용도로 평가 시 시세 하방 리스크가 더 큼.

3-3. 본건 시세 추정

본건은 집합건물로서 토지+건물 일괄 평가됩니다. 전용면적은 건축물대장 확인이 필요하나, 에덴빌8차 1층101호로서 소형 집합건물(추정 전용 40~60m2)입니다.

시나리오 기준 추정 시세 산출 근거
비관적 (상가 기준) 상가 경매 환경 반영 2.0~2.5억 감정가 x 60% 수준, 상가 냉각
보수적 (주택 기준, 1층 할인) 노후+1층+용도 불일치 2.5~3.0억 평당 1,800만 x 15평 기준
중간 주택 기준 적정 3.0~3.5억 감정가 수준
낙관적 용도변경 후 주택 시세 3.5~4.0억 중곡동 빌라 시세 적용

감정가 342,000,000원은 2024~2025년 감정 기준으로 적정 수준으로 판단. 다만 상가 시장 냉각 + 용도 불일치 + 1층이라는 점에서 실제 거래가는 감정가 하회 가능성 있음.
