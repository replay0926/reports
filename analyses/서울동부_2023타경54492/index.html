  • [ ] 제시외 건물 4건: 미등기 건물 — 소유권 분쟁 가능성
  • [ ] 채무자 송달 문제: 4회 폐문부재 — 채무자 소재 불명, 명도 시 어려움 예상

8. 추가 확인 사항

필수 확인

  1. 등기부등본 확인: 건물(목록1) + 토지(목록2) 등기사항전부증명서 열람
    • 근저당권, 전세권, 지상권 등 권리관계 상세 확인
    • 공유 지분 비율 확인 (매각 대상 지분율)
  2. 매각물건명세서 확인: 인수되는 권리, 소멸되는 권리 명확히 구분
  3. 현황조사서 확인: 유치원 운영 상세 (임차인 정보, 임대차 계약 내용)
  4. 감정평가서 확인: 토지/건물 각각의 감정가 내역, 개별 지분 가치
  5. 공유자 지분비율: 채무자 3인의 개별 지분율 및 매각 대상 지분 범위

권장 확인

  1. 유치원 인가 현황: 관할 교육지원청 유치원 인가/폐원 여부
  2. 관련 판결문: 서울중앙지법 2012가단42671 판결 내용 (원인 채권 확인)
  3. 현대프라임아파트 관리단/관리사무소: 유치원동 관리 현황, 관리비 체납 여부
  4. 구의동 631-1 토지이용계획: 용도지역, 건폐율/용적율, 개발계획
  5. 가압류 채권액: 가압류권자 2인의 청구금액 확인 (배당 시뮬레이션 필요)

물건 특성

서울 광진구 구의동 소재 현대프라임아파트 단지 내 유치원 건물 + 토지 공유지분 매각 건이다. 감정가 128.3억 원에서 7차 유찰로 33.6억 원(감정가의 26.2%)까지 하락했다. 지분매각이라는 점이 가장 큰 특징이자 리스크 요인이다.

투자 매력 요인

  1. 높은 할인율: 감정가 대비 73.8% 할인으로 가격 메리트 존재
  2. 서울 광진구 입지: 구의동 역세권 인근, 현대프라임아파트 단지 내 위치
  3. 6회 연속 유찰: 경쟁률 낮을 가능성 (그러나 7차에서 관심 증가 가능)

주요 리스크

  1. 지분매각의 한계: 공유 지분만 취득하므로 단독 처분/활용 불가. 공유물분할청구 소송(민법 제268~270조) 필요하며, 시간과 비용 소요

  3. 유치원 운영 리스크: 현재 유치원으로 사용 중이므로 명도에 상당한 어려움 예상. 영유아보육법/유아교육법상 보호 조항 확인 필요
  4. 대규모 자금 필요: 보증금만 3.4억 원, 낙찰 시 잔금 약 30억 원 이상 필요
