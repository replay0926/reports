8. 추가 확인 사항

반드시 확인해야 할 항목

  1. 매각물건명세서 열람

    • 임차인 배OO, 박OO의 보증금 금액, 대항력 취득일, 확정일자 유무
    • 인수 조건 여부 (대항력 있는 임차인인 경우 보증금 인수 가능)
    • 상가임대차보호법상 최우선변제금 해당 여부

  2. 현황조사서 확인

    • 실제 점유 상태 (영업 중인지, 공실인지)
    • 점포의 실제 면적 및 용도
    • 테크노마트 내 위치와 동선

  3. 감정평가서 확인

    • 호실별 전용면적, 공용면적
    • 감정가 산출 근거 (비교사례, 수익환원법 등)
    • 평당 단가 확인

  4. 등기부등본 열람

    • 근저당권 설정 금액 및 설정일
    • 가압류 금액
    • 압류 내역 상세
    • 소유권 이전 이력

  5. 테크노마트21 현장 확인

    • 해당 층 영업 현황 및 공실률
    • 인근 점포 임대료 수준
    • 관리비 구조 (평당 관리비)
    • 주변 상권 동향 (구의역 일대)

  6. 세금 체납 확인

    • 압류권자(서OOOO OOO): 체납세금 종류 및 금액
    • 교부권자(광OO): 지방세 체납액
